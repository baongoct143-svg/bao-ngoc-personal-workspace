# Trần Bảo Ngọc · Personal Workbench

Trang web tĩnh song ngữ Việt–Trung. Các tương tác mẫu (công việc, ghi chú, kết bạn, kế hoạch) lưu trong bộ nhớ trình duyệt của từng người xem.

## Deploy bằng GitHub Pages

1. Tạo một repository **public** trên GitHub, ví dụ `tran-bao-ngoc-workbench`.
2. Tải `index.html`, `.nojekyll` và `README.md` trong thư mục này lên thư mục gốc của repository.
3. Mở **Settings → Pages**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`, rồi nhấn **Save**.
4. Đợi GitHub Pages hoàn tất; liên kết chia sẻ sẽ xuất hiện tại trang Settings → Pages.

Cập nhật trang bằng cách thay `index.html` trong repository.
